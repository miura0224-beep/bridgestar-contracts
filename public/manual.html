BRIDGE STAR / OPERATION GUIDE

申込から署名まで、
迷わず進めるために。

事務局・保護者・コーチの操作を、順番に確認できます。
契約と請求書の発行は、別の手続きです。

01 / 全体の流れ

はじめに

保護者が申込入力→事務局が確認→別担当者が承認→保護者が署名

生徒契約は、保護者がプラン・開始希望日などを選び、事務局が契約内容を確定します。コーチ契約は、事務局が報酬・期間などを入力して作成します。

申込の送信だけでは契約は成立しません。

事務局の確認後、別のメールで届く契約書を読み、署名して完了です。

  • 事務局：登録したメールアドレスと8桁の確認コードでログイン。
  • 保護者・コーチ：専用メールリンクと6桁の確認コードで手続き。管理者アカウントは不要です。
  • 契約書に記載する通常月額は、コーチング月4回を全額の基準とします。初月の請求額は別途ご案内します。
02 / 管理責任者

利用前に準備すること

  1. 契約管理にログイン。登録メールアドレスを入力し「確認コードを受け取る」を押します。届いた8桁コードを10分以内に入力します。
  2. 「チーム」で担当者を登録。メールアドレス・氏名・役割を設定します。作成者とは別の承認担当を最低1人用意してください。
  3. 「契約のひな形」で正式版を確認。原本PDFと条項を照合し、必要な内容を整えて使用を承認した新しい版を保存します。
役割 主な操作
管理責任者 メンバー・ひな形の管理、契約操作
承認担当 契約作成、他の人が作った契約の承認、送信
作成担当 申込案内、契約作成、承認依頼、承認済み契約の送信
閲覧担当 申込・契約・履歴の確認、文書の保存

候補ひな形は、そのまま送信できません。新しい版を登録しても、すでに作成した契約には自動反映されません。

初月請求ルールの改訂版を選んでください。

元の紙書式にある「16日以降は半額」は旧ルールです。「初月回数別・請求書別途」の候補版では第3条4項を更新しています。他の契約条項も確認してから使用を承認してください。

03 / 事務局

保護者に申込シートを案内する

  1. 左メニューの「入塾申込」を開きます。
  2. 保護者氏名と保護者のメールアドレスを入力します。
  3. 宛先を確認し、「申込シートの案内を送る」を押します。この操作で案内メールが送信待ちに登録されます。
  4. 申込一覧で進捗を確認します。送信状態は「送信状況」で確認できます。
入力待ち 保護者へ案内済みで、まだ入力内容が提出されていません。
事務局の確認待ち 保護者が入力内容を提出しました。内容を確認してください。
契約書を作成済み 申込から下書きの契約を作成済みです。「契約書を見る」で開けます。
取消済み その案内リンクは利用できません。

入力リンクは7日間有効です。宛先違いや期限切れの場合は、旧案内を取り消して新しい案内を作成します。保護者用の個別リンクを他のご家庭に共有しないでください。

04 / 保護者

申込シートを入力する

  1. 「入塾申込シートのご入力」メールのリンクを開きます。
  2. 「確認コードを送る」を押し、同じメールアドレスに届く6桁コードを入力します。
  3. 生徒情報を入力：氏名・フリガナ・学校・学年・メール・住所。生年月日と携帯番号は任意です。
  4. 保護者情報を入力：氏名・フリガナ・携帯番号・住所。確認済みメールは変更できません。「生徒の住所をコピー」も使えます。
  5. 希望プラン・開始希望日を選択。必要なら「読書と対話」を追加します。
  6. 個人情報の取り扱いと、後日契約署名を行うことを確認し「入力内容を確認」を押します。
  7. 確認画面で見直して「この内容を事務局へ送る」を押します。直す場合は「修正する」で戻れます。

送信後は事務局の確認をお待ちください。修正したい場合は事務局へ連絡してください。ページを閉じる前の未送信入力は自動保存されません。

05 / 事務局・承認担当

申込を確認して契約書を作る

  1. 「入塾申込」で「事務局の確認待ち」の内容を確認します。
  2. 「確認して契約書を作成」を押します。保護者の入力したプラン・開始希望日・連絡先が引き継がれます。
  3. 使用承認済みのひな形、契約期間、担当者を設定。条件を変更する場合は、保護者と確認してから反映します。
  4. 「契約内容を確認」→「下書きを保存」と進みます。この時点では署名依頼は送られません。
  5. 契約の詳細画面で承認を依頼します。別の担当者がログインして内容を確認・承認します。
  6. 承認で契約PDFが確定します。宛先とPDFを確認して、署名依頼を送信します。

確認するポイント

  • 申込時の希望と、契約書のプラン・通常月額・開始日が一致しているか。
  • 契約者・署名者が保護者で、送信先が正しいか。
  • 終了日と個別合意事項に誤りがないか。
  • 初月は別途請求であることが契約条項に記載されているか。

原則として1つの申込から作る契約は1件です。同時操作による重複作成は拒否されます。元の申込内容は確認用として残ります。

06 / 事務局

コーチとの契約を作る

  1. 「契約一覧」から新しい契約を作成し、「コーチとの契約」を選びます。
  2. 氏名・メール・住所・電話・指導科目・通常指導時給・開始日・終了日を入力します。
  3. 「業務委託説明資料の原本」と「承諾書の原本」を確認し、承認済みのコーチひな形を選びます。
  4. 下書き保存→別担当者による承認→署名依頼と進みます。

初期設定には試用期間・コーチング・Slack対応・品質加算・継続手当・研修費が含まれます。個別契約の条件と一致するか、必ず生成された本文を確認してください。コーチは届いたリンクから確認・署名します。

07 / 保護者・コーチ

確定した契約書に署名する

  1. 事務局から届く署名依頼メールのリンクを開きます。申込シートとは別のリンクです。
  2. メールに届く6桁コードで本人確認します。
  3. 契約書をPDFで受け取ること、閲覧・保存ができること、紙での受け取りも選べることを確認します。
  4. 契約本文を読み、PDFを保存します。プラン・開始日・通常月額などをご確認ください。
  5. 保存できたことと署名権限を確認し、宛名と同じ氏名を入力して署名します。
  6. 完了画面から契約PDF・合意記録PDFを保存します。

内容が違う場合は署名せず、画面の修正依頼から事務局へ伝えてください。紙を希望する場合は「紙での受け取りを相談」を選びます。確認コードは他人へ伝えないでください。

08 / 事務局・保護者

請求書は契約内容に基づいて別途送付

このシステムで確定するもの

  • 契約プラン・通常月額
  • サービス提供開始日・契約期間
  • オプション・共通条項・個別合意
  • 署名・合意の記録

事務局が別途案内するもの

  • 当月に実施できるコーチング回数
  • 契約内容に基づく初月の請求額
  • 請求書・決済方法・支払期日

通常月はコーチング4回を全額の基準とし、初月は開始日と実施可能回数によって変動します。契約画面では開始日だけから金額を決めず、一律半額にもしていません。

請求書の作成・送付・入金管理は、このシステムの機能には含まれません。事務局の請求業務で対応します。請求に疑問がある場合は、署名済み契約のプラン・期間を照合して事務局へお問い合わせください。

09 / 共同作業

保存・変更・取消の使い分け

したいこと 操作
契約を探す 「契約一覧」の検索・種別・進捗絞り込みを使います。
担当者に補足する 契約詳細の内部メモを使います。契約本文に入れる条件は「個別合意事項」に記載します。
契約内容を変更する 「修正して新しく作成」を使い、新しい契約として承認・署名をやり直します。新旧の重複に注意してください。
署名依頼を再送する 契約詳細から再送します。旧リンクと既存の署名セッションは無効になります。
署名前に取り消す 契約詳細から取消操作を行います。署名済み契約は取り消せません。
記録を保管する 契約PDF・合意記録PDF・詳細記録を保存します。契約一覧はCSVでも保存できます。

送信後の契約本文を上書きすることはできません。履歴と元の文書を残し、変更は新しい契約で行います。署名済み契約の解約・変更は事務局で別途手続きしてください。

お相手のリンクは原則7日間有効です。期限後の再交付は事務局へご依頼ください。

10 / よくあるご質問

困ったとき

ログイン・確認メールが届きません

メールアドレスと迷惑メールフォルダをご確認ください。管理者は登録済みメールだけ利用できます。事務局は「送信状況」で失敗の有無を確認します。「送信済み」は配信サービスが受け付けた状態で、受信箱への到達を保証する表示ではありません。

確認コードが使えません

管理者は8桁、お相手は6桁です。有効期限は10分、入力は最大5回です。再送した場合は最新のコードを使ってください。再送直後に制限が出た場合は少し待って操作してください。

自分が作った契約を承認できません

作成者とは別の管理責任者または承認担当が承認する設計です。「チーム」で別担当者を登録してください。

未承認ひな形・旧半額条項という表示が出ます

管理責任者が原本を確認し、現行の請求ルールに対応した新しい版を登録してください。すでに作った下書きは、正式版を選んで新しく作り直します。

保護者が申込を送った後に間違いが見つかりました

保護者は事務局へ連絡してください。事務局は確認して契約作成画面で修正できます。入力をやり直してもらう場合は、旧申込を取り消して新しい案内を送ります。

「別の担当者が更新しました」と出ます

再読み込みして現在の状態を確認してください。繰り返し押す前に、すでに処理が完了していないか確認します。

請求書や支払リンクがありません

請求書は事務局から別途送付します。契約システム内に決済画面・入金管理はありません。

電子署名の記録はどのようなものですか

メール確認、契約本文・PDF、同意・署名日時などを自社システムで記録します。第三者電子証明書・認定タイムスタンプは付与していません。

11 / 塾生の各種手続き

諸変更届

退会、プラン、住所、電話番号、メールアドレス、在籍学校・学年、保護者氏名・支払情報、その他の8種類を受け付けます。

事務局：入力リンクの案内

  1. 管理画面の「諸変更届」を開きます。
  2. 保護者氏名と、事務局で確認したメールアドレスを入力して案内を送ります。
  3. リンクは7日間有効です。期限切れ・再提出の場合は新しい案内を送ります。入力前の案内のみ取り消せます。

保護者：届出の提出

  1. メールのリンクを開き、6桁の確認コードでメールを確認します。
  2. 届出の種類を選び、対象者・変更日・必要事項を入力します。
  3. 塾生と保護者で内容を確認し、それぞれの確認氏名を入力します。保護者のメール確認と氏名入力を記録します。
  4. 確認画面を読み、「この内容で届出を提出する」を押します。受付番号と提出日時を確認してください。
退会・プラン変更の提出期限

原書式では希望月の前月10日（必着）までです。期限を過ぎた場合の扱いを画面にも表示します。提出を受け付けた日時は保持し、実際の適用日・退会日・精算は、事務局が適用中の契約に基づき確認します。

事務局：確認・処理結果の記録

  1. 「諸変更届」で「受付済み」を絞り込み、提出内容を開きます。
  2. 「確認・処理結果を記録」で確認中・処理完了・再提出のご案内を選び、対応内容を残します。
  3. 退会・プラン変更を処理完了にするときは、確認した適用日・退会日を入力します。
  4. 必要な登録情報の更新、変更契約、請求・決済の手続きを別途行います。処理結果のメール連絡も別途行ってください。

事務局の記入内容は、保護者が有効期限内に同じリンクを開いた際にも表示されます。期限後は事務局へお問い合わせください。

提出済みの内容と契約書は保存されます。

届出によって締結済み契約を直接書き換えることはありません。再提出は新しい案内で受け付け、元の届出も残します。各担当者の対応は「処理履歴」から確認できます。

支払情報・メールアドレスの変更

支払口座・カード情報の変更届には、口座番号・カード番号を入力しません。事務局が案内する決済リンクで登録してください。退会届には、返金がある場合に限り返金口座を入力できます。

メール変更は事務局が新しい宛先を確認してから反映します。以前のメールが使えない場合、事務局に連絡して本人確認を受けてください。
