入塾手続きマニュアル

契約管理画面を開く手順を見る

手続きの流れ

申込案内 → 保護者の入力 → 契約作成・承認依頼 → 承認 → 署名依頼 → 保護者の署名 → 請求書の送付

事務局は自分のアカウントで契約を作成します。承認依頼メールはユウキ先生に、承認完了メールは契約を作成した担当者に届きます。

01 / 事務局

申込シートを案内する

  1. 契約管理画面に登録済みメールアドレスでログインします。メールに届く8桁の確認コードを10分以内に入力してください。
  2. 「入塾申込」を開き、保護者氏名とメールアドレスを入力します。
  3. 宛先を確認し、「申込シートの案内を送る」を押します。
  4. 保護者の入力を待ちます。提出されると「事務局の確認待ち」になります。

案内リンクの有効期限は7日間です。メールの送信状況は「送信状況」で確認できます。

02 / 事務局

契約を作成して承認を依頼する

  1. 「入塾申込」の「事務局の確認待ち」を開き、「確認して契約書を作成」を押します。
  2. 次の内容を確認します。
    • 生徒・保護者の氏名と署名依頼先メールアドレス
    • プラン、読書と対話の有無、通常月額
    • 開始希望日と、その日から受講を開始できるか
  3. 使用承認済みのひな形を選び、契約期間・担当者・必要な個別合意事項を設定します。申込と異なる条件にする場合は、保護者に確認してから反映します。
  4. 「契約内容を確認」→「下書きを保存」と進みます。
  5. 契約詳細で「社内承認を依頼」を押します。ユウキ先生へ承認依頼メールが送られます。

ここでは保護者への署名依頼は送られません。承認完了メールを待って、手順04へ進みます。

「個別合意事項」は契約書に記載されます。内部連絡は「チームのメモ」に記入してください。

03 / 承認担当

契約内容を承認する

  1. 承認依頼メールの「内容を確認して承認する」を開きます。ログイン画面が出た場合はログインします。
  2. 申込内容、宛先、プラン、料金、契約期間、個別合意事項、契約全文を確認します。
  3. 確認欄にチェックし、「この内容を承認」を押します。

承認完了メールが契約を作成した事務局担当者へ届きます。修正が必要な場合は、修正箇所を記入して「差し戻す」を押します。

04 / 事務局

保護者へ署名を依頼する

  1. 承認完了メールのボタンから契約詳細を開き、「送信準備完了」を確認します。
  2. 「PDFを保存」で契約書を確認し、送信先を確認します。
  3. 「署名依頼を送信」を押します。
  4. メールの送信状況を確認し、保護者の署名を待ちます。

保護者から操作方法を聞かれた場合は、入塾手続きの説明動画を案内してください。

05 / 事務局

締結を確認する

  1. 契約一覧で「締結済み」を確認します。「署名待ち」の間は署名が完了していません。
  2. 契約PDFと合意記録PDFを保存します。
  3. 受講開始の案内を担当者へ引き継ぎます。
06 / 事務局

請求書を別途送付する

  1. 契約内容、開始日、当月に実施できるコーチング回数を確認します。
  2. 料金ルールに沿って請求額を確認し、請求書を作成・送付します。

通常月はコーチング月4回を全額の基準とします。初月は開始日と実施可能回数に応じて請求額が変わります。請求書は契約システムから自動発行されません。

手続きが進まないとき

状況対応
承認完了メールが届かない契約の状態とメール送信状況を確認します。「下書き」なら「社内承認を依頼」を押します。「承認待ち」なら承認担当に確認します。「送信準備完了」なら手順04へ進めます。
差し戻された契約詳細の「これまでの記録」で理由を確認し、内容を修正して承認を依頼し直します。
契約内容を修正したい「修正して新しく作成」を使います。旧契約は署名前であれば取り消し、新旧の契約を重複して送らないよう確認します。
未承認ひな形・旧半額条項のエラー管理責任者に正式なひな形を確認し、正式版を使って契約を作り直します。
他の担当者が更新したと表示される再読み込みして最新の状態を確認します。
保護者に署名メールが届かない宛先、迷惑メール、送信状況を確認します。「署名依頼を再送」を使った場合は、最新のメールを開くよう案内します。
